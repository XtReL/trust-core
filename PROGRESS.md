## Журнал решений

- **Ноль внешних зависимостей в ядре.** Минимальная цепочка поставок для продукта про доверие; сборка работает где угодно. Сверка с эталоном вынесена в отдельный модуль `interop/`.
- **Ed25519, PEM.** Стандартные форматы, читаются openssl.
- **Сначала `filelog`, потом Tessera.** Первый срез должен быть проверяем на локальной машине; интерфейс `tlog.Log` позволяет заменить бэкенд без изменений в вертикалях.
- **Раздельные ключи оператора журнала и аттестатора.** В режиме Action это разные роли; при желании можно использовать один ключ.
- **Ресурс SpiceDB — числовой ID репозитория GitHub.** Допустим в ID объекта SpiceDB (имя с точкой — нет) и не меняется при переименовании.
- **CI-сканеры запускаются на каждом шаге.** gosec нашёл проблемы, не видимые сборкой; первые зелёные прогоны появились только после исправления ключа GitGuardian.
- **Гигиена применяется через bundle с эталонными хэшами деревьев.** Результат у пользователя байт в байт совпадает с проверенным.
- **Код и комментарии на английском, документация на русском.** Код рассчитан на глобальную аудиторию, документация — для текущей работы.
