# Правила для агента

- Перед каждым push запускать `scripts/check.sh` и показывать его полный
  вывод. Это единый источник проверок — он выполняет то же самое, что
  `.github/workflows/ci.yml` (задания `test` и `interop`), и падает на
  первой ошибке.
- PR не сливать. Релизы (теги) ставит человек.
- В ядре (всё, кроме `interop/`) — только стандартная библиотека Go,
  никаких внешних зависимостей. Внешние зависимости допустимы только в
  `interop/`, отдельном модуле для сверки с эталонными реализациями.
- Форматы стандартные и неизменные: DSSE, in-toto Statement v1, RFC 6962,
  C2SP checkpoint/signed-note. Любое изменение формата или формата на
  диске — только после решения человека.
- Обратная совместимость: журналы и чекпоинты, созданные прежними
  версиями, должны проверяться новой версией.
- GitHub Actions только по полным SHA (тег — в комментарии, версия не
  используется для разрешения действия).
- При сомнении в архитектурном решении — остановиться и спросить.
